# WebLocal

Landing page and sample websites for local businesses, built with React, TypeScript, and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Deploy to GitHub Pages

The `Deploy to GitHub Pages` workflow builds the site and publishes the `dist` directory on every push to `main`. In the repository settings, select **Settings → Pages → Build and deployment → GitHub Actions** as the source.
